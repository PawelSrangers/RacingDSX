# Architecture Decision Records

Решения, принятые при доработке RacingDSX под Forza Horizon 6. Каждый файл — одно решение:
контекст, что выбрали, что отвергли и почему, и с какими последствиями живём.

Формат — по Майклу Найгарду, новые ADR копируют [шаблон](0000-template.md). ADR не
переписываются задним числом: если решение меняется, пишется новый ADR, у которого в разделе
`Relations` стоит `Supersedes: NNNN`, а у старого меняется только строка статуса — на
`Superseded by NNNN`.

С ADR-0011 у каждого ADR есть машиночитаемый раздел `Relations` (`Depends-on`, `Supersedes`,
`Constrains`, `Related`; `none`, если связей нет). Из него строится граф зависимостей
решений. В ADR-0001…0010 этот раздел добавлен задним числом, остальной их текст не менялся.
