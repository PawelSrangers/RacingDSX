# Architecture Decision Records

Решения, принятые при доработке RacingDSX под Forza Horizon 6. Каждый файл — одно решение:
контекст, что выбрали, что отвергли и почему, и с какими последствиями живём.

Формат — по Майклу Найгарду. ADR не переписываются задним числом: если решение меняется,
пишется новый ADR со статусом «Заменяет ADR-000N», а у старого статус меняется на
«Заменён ADR-000M».
