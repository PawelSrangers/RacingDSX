# Spec: Throttle trigger

- Status: Draft
- Feature ID: THROTTLE
- Owner: abramovdima1998 (владелец репозитория)
- Related ADRs: 0001, 0004, 0008, 0010
- Related specs: specs/dsx-output.md, specs/telemetry-input.md, specs/brake-trigger.md, specs/settings-ui.md

## Problem

Правый (газовый) триггер DualSense передаёт нагрузку на машину: сопротивление растёт с
ускорением, а при потере сцепления (пробуксовка, снос передней оси) триггер вибрирует.
Логика газа унаследована от апстрима 0.6.7 без изменений: в отличие от тормоза (ADR-0009),
потеря сцепления здесь по-прежнему определяется по нормированному проскальзыванию шин, то
есть зависит от покрытия.

Спецификация фиксирует текущее поведение как есть, чтобы любые изменения газа делались
осознанно, через новую версию спецификации. Части поведения, похожие на ошибки, вынесены в
Open questions, а не исправлены.

## Goals

- Описать точно, какую команду получает правый триггер при данных телеметрии и настройках.
- Зафиксировать смысл каждой настройки `throttleSettings` в `RacingDSX.json`.
- Отделить подтверждённое поведение от вопросов, требующих решения владельца.

## Non-goals / Out of scope

- Переработка логики газа (по скорости колёс, как у тормоза, или иначе). Газ не
  перепроектирован; это будущая работа через новый spec-PR.
- Независимость от покрытия: потеря сцепления на газе зависит от нормировки проскальзывания
  в игре (на гравии и асфальте пороги срабатывают по-разному). Это известное свойство, не
  требование.
- Стики, кнопки и любые входы геймпада: RacingDSX их не трогает.
- Доставка команд в DSX (частота, склейка, дедупликация, удержание короткой вибрации до
  слота отправки) — `specs/dsx-output.md`, REQ-OUTPUT-006.
- Триггер вне гонки и при остановке телеметрии — `specs/telemetry-input.md`, REQ-OUTPUT-007.
- Проверка на профиле Dirt: код тот же, реальной записью не проверялся.

## Requirements

Формат команды для правого триггера (UDP API DSX, `type` 1, `parameters[1]` = 2):

- обычный режим: `[0, 2, 0, 0, 0]`;
- сопротивление: `[0, 2, 13, 0, F]`, `F` — сила;
- вибрация: `[0, 2, 12, 9, Fr, S, P, 0, 0, 0, 0]` — CustomTriggerValue / VibrateResistance.

Обозначения (всё из телеметрии текущего кадра):

- «ускорение» `A` = √(`TurnAccelerationScale` × ax² + `ForwardAccelerationScale` × az²), где
  ax — боковое, az — продольное ускорение машины (м/с²);
- «проскальзывание передней оси» — среднее |комбинированного проскальзывания| двух передних
  шин, «задней оси» — двух задних, «общее» — всех четырёх;
- «газ» — `Accelerator` (0–255).

### REQ-THROTTLE-001: Режим газового триггера

- Status: Active
- Description: Настройка `throttleSettings.TriggerMode` MUST определять поведение:
  `Off` (0) — правый триггер всегда `[0, 2, 0, 0, 0]`; `Resistance` (1) — всегда сопротивление
  по REQ-THROTTLE-002, без вибрации; `Vibration` (2) — REQ-THROTTLE-002…005. По умолчанию
  `Vibration`.
- Acceptance criteria:
  - Given режим `Off`, when любые газ, ускорение и проскальзывание, then правый триггер
    `[0, 2, 0, 0, 0]`.
  - Given режим `Resistance` и проскальзывание передней оси 3.0, then правый триггер в
    режиме 13 с силой по REQ-THROTTLE-002.
  - Проверка: нет автоматической проверки.

### REQ-THROTTLE-002: Сопротивление по ускорению

- Status: Active
- Description: Когда нет потери сцепления (REQ-THROTTLE-003) или режим — `Resistance`,
  система MUST отправлять `[0, 2, 13, 0, F]`, где `F` растёт линейно от `MinResistance` при
  `A` = 0 до `MaxResistance` при `A` ≥ `AccelerationLimit`, сглаженное с коэффициентом
  `ResistanceSmoothing` и умноженное на `EffectIntensity`. Сила MUST NOT зависеть от
  положения педали газа. При `AccelerationLimit` = 0 сила MUST быть `MinResistance` (без
  деления на ноль).
- Acceptance criteria:
  - Given настройки по умолчанию, ax = 0, az = 5 м/с², нет потери сцепления, when держится
    постоянно, then `F` в пределах [`T`−1, `T`], `T` = floor(5 × 3 / 10) = 1.
  - Given az ≥ 10 м/с², then `T` = `MaxResistance` = 3, `F` ∈ [2, 3] (о нижней границе см.
    OQ-6).
  - Проверка: нет автоматической проверки (`fake_forza.ps1` не умеет фиксировать ускорение
    и газ, только синусоидальная развёртка).

### REQ-THROTTLE-003: Условие потери сцепления

- Status: Active
- Description: Потеря сцепления на газе — это пробуксовка, когда водитель жмёт газ. Она MUST
  определяться так: газ больше `VibrationModeStart` И (проскальзывание передней оси больше
  `GripLossValue` ИЛИ (проскальзывание задней оси больше `GripLossValue` И газ больше 200)).
  Проскальзывание без газа (торможение, накат, занос) MUST NOT считаться потерей сцепления:
  правый триггер тогда ведёт себя по REQ-THROTTLE-002.
- Acceptance criteria:
  - Given `GripLossValue` = 0.6, `VibrationModeStart` = 5, проскальзывание передней оси 0.7,
    задней 0, газ 0 (торможение с проскальзыванием передка), then условие не выполнено и
    правый триггер получает сопротивление по REQ-THROTTLE-002 (0…`MaxResistance`).
  - Given те же настройки, проскальзывание передней оси 0.7, газ 6, then условие выполнено.
  - Given проскальзывание задней оси 1.0, передней 0.1, газ 200, then условие не выполнено;
    газ 201 — выполнено.
  - Проверка: нет автоматической проверки. Вручную: `tools/fake_forza.ps1 -Slip 1.0 -Port 5310`
    (газ 0) и `tools/fake_dsx.ps1 -Port 6970` в песочнице — сила правого триггера ≤ 3.

### REQ-THROTTLE-004: Вибрация при потере сцепления под газом

- Status: Active
- Description: В режиме `Vibration` при потере сцепления система MUST вычислять частоту
  `Fr` = floor(линейно от 0 при общем проскальзывании = `GripLossValue` до `MaxVibration` при
  общем проскальзывании ≥ 5), сглаженную с коэффициентом `VibrationSmoothing`, и жёсткость
  `S` = floor(линейно от `MinStiffness` при `A` = 0 до `MaxStiffness` при
  `A` ≥ `AccelerationLimit`), сглаженную с коэффициентом `ResistanceSmoothing`. Если
  сглаженная частота больше `MinVibration` и газ больше `VibrationModeStart`, система MUST
  отправить `[0, 2, 12, 9, Fr × EffectIntensity, S × EffectIntensity, VibrationModeStart, 0, 0,
  0, 0]`. Сглаживание частоты MUST NOT сбрасываться в начале нового эпизода пробуксовки (в
  отличие от тормоза, REQ-BRAKE-005).
- Acceptance criteria:
  - Given настройки по умолчанию, общее проскальзывание 2.8, проскальзывание передней оси 2.8,
    газ 255, ax = 0, az = 5 м/с², then `Fr` = floor(2.2 × 55 / 4.4) = 27 и команда
    `[0, 2, 12, 9, 27, S, 5, 0, 0, 0, 0]` с `S` около floor(255 − 5 × 80 / 10) = 215.
  - Given общее проскальзывание 0.9 (частота floor(0.3 × 55 / 4.4) = 3 ≤ `MinVibration` = 5),
    then вибрации нет (REQ-THROTTLE-005).
  - Проверка: нет автоматической проверки. Короткие пробуксовки доходят до DSX по
    REQ-OUTPUT-006.

### REQ-THROTTLE-005: Потеря сцепления ниже порога вибрации

- Status: Active
- Description: В режиме `Vibration` при потере сцепления (то есть под газом, REQ-THROTTLE-003),
  когда сглаженная частота ≤ `MinVibration`, система MUST отправлять
  `[0, 2, 13, 0, S × EffectIntensity]`, где `S` — жёсткость из REQ-THROTTLE-004 (шкала
  `MinStiffness`…`MaxStiffness`, по умолчанию 255…175): при слабой пробуксовке под газом
  триггер становится тугим, но не вибрирует.
- Acceptance criteria:
  - Given настройки по умолчанию, проскальзывание передней оси 1.0, общее 0.9, газ 255,
    ax = az = 0, when держится несколько кадров, then правый триггер `[0, 2, 13, 0, F]` с `F`,
    приближающимся к 255.
  - Given то же, но газ 0, then правый триггер — сопротивление REQ-THROTTLE-002 (≤ 3).
  - Проверка: нет автоматической проверки.

### REQ-THROTTLE-006: Сила эффекта

- Status: Active
- Description: `EffectIntensity` (0.0–1.0) MUST масштабировать силу сопротивления, частоту и
  жёсткость вибрации правого триггера (результат округляется вниз). Позиция начала вибрации
  (`VibrationModeStart`) MUST NOT масштабироваться.
- Acceptance criteria:
  - Given `EffectIntensity` = 0.5 и условия первого примера REQ-THROTTLE-004, then
    `Fr` = 13, позиция = 5.
  - Проверка: нет автоматической проверки.

## Constraints

Значения из кода (`GameParsers/Parser.cs`, `Config/ThrottleSettings.cs`,
`Config/ConfigHandler.cs`) на 2026-10-19.

- Значения по умолчанию (`throttleSettings`): `TriggerMode` 2 (Vibration), `GripLossValue`
  0.6 (в профиле Dirt по умолчанию 0.4), `EffectIntensity` 1.0, `TurnAccelerationScale` 0.25,
  `ForwardAccelerationScale` 1.0, `AccelerationLimit` 10, `VibrationModeStart` 5,
  `MinVibration` 5, `MaxVibration` 55, `VibrationSmoothing` 1.0, `MinStiffness` 255,
  `MaxStiffness` 175, `MinResistance` 0, `MaxResistance` 3, `ResistanceSmoothing` 0.9.
- Верхняя граница шкалы проскальзывания для частоты — константа 5.0, порог газа для задней
  оси — константа 200 (> 200). Не настраиваются.
- Линейные отображения зажимают вход в свой диапазон; пустой диапазон даёт нижнее значение
  выхода; NaN на входе считается нижней границей.
- Сглаживание: `новое = floor(α × расчётное + (1 − α) × предыдущее)`. Сила сопротивления и
  жёсткость вибрации делят одно состояние сглаживания (OQ-2); начальное значение 1 при каждом
  старте воркера, начальная частота 0.
- Расчёт на каждом кадре телеметрии; отправка ограничена `specs/dsx-output.md`.
- Реальные записи газ не покрывают (ADR-0014): инструментов анализа газа нет.

## Open questions

- **OQ-1 (решён 2026-10-19):** раньше передняя ось проверялась без условия на газ, и на
  торможении с проскальзыванием передка правый триггер получал жёсткость 175–255 (в записях
  13–15% кадров гонки). Владелец: «правый триггер должен получать сопротивление при
  пробуксовке, когда нажимаешь на газ». REQ-THROTTLE-003 и 005 изменены.
- **OQ-2 (non-blocking):** жёсткость вибрации и обычное сопротивление делят одно состояние
  сглаживания (`Parser.cs:210`, `213`, `238`, `240`), хотя шкалы разные (175–255 и 0–3). Для
  тормоза та же утечка исправлена в ADR-0009. При `ResistanceSmoothing` = 0.9 после эпизода
  сопротивление спадает со ~200 за 2–3 кадра.
- **OQ-3 (non-blocking):** `VibrationModeStart` газа используется в двух смыслах: порог газа
  (0–255) для вибрации (`Parser.cs:217`) и позиция начала вибрации в команде DSX
  (`Parser.cs:228`). У тормоза это две разные настройки (`VibrationModeStart` и
  `VibrationStart`).
- **OQ-4 (non-blocking):** `MinVibration` газа — не нижняя граница шкалы частоты (шкала
  0…`MaxVibration`, `Parser.cs:208`), а порог отсечения (`Parser.cs:216`). Подпись UI
  «Min Throttle Vibration» это не передаёт, а ADR-0010 утверждает, что «вкладка газа
  согласована полностью». Требует решения: подпись или поведение.
- **OQ-5 (non-blocking):** у тормоза каждая блокировка начинается с полной силы
  (REQ-BRAKE-005), у газа сглаживание частоты продолжается с прошлого эпизода
  (`Parser.cs:211`, `214`). При `VibrationSmoothing` = 1 (по умолчанию) разницы нет.
- **OQ-6 (non-blocking):** сглаживание с округлением вниз (`Parser.cs:317-320`) при подходе
  снизу застревает на `T − 1`: при `ResistanceSmoothing` = 0.9 сила устанавливается 2, а не
  `MaxResistance` = 3. Тот же эффект, что у тормоза (brake-trigger.md, OQ-3).
